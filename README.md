# Install

## [Manjaro Dotfiles](https://github.com/Ckrenzer/dfm/tree/arch)
```
git clone https://github.com/Ckrenzer/dfm.git && \
cd dfm && \
git checkout arch && \
cd .. && \
git clone https://github.com/Ckrenzer/swm.git && \
cd swm && \
source arch/initialize_manjaro.sh
```

## [Ubuntu Dotfiles](https://github.com/Ckrenzer/dfm/tree/ubuntu)
```
git clone https://github.com/Ckrenzer/dfm.git && \
cd dfm && \
git checkout ubuntu && \
source transfer.sh
```

## [Windows Dotfiles](https://github.com/Ckrenzer/dfm/tree/windows)
```
git clone https://github.com/Ckrenzer/dfm.git && \
cd dfm && \
git checkout windows
```
